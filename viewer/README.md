# 调用链阅读器

本说明仅介绍 `viewer/events.py` 这个日志查看小工具。它读取已导出的 `events.jsonl`，将完整调用链整理成可在浏览器中阅读的页面。整体研究项目、仿真引擎和实验运行方式见[项目 README](../README.md)。

## 功能

- 按天查看任务指令、思考、工具调用、返回、回复及验收结果。
- 自动配对调用与返回，支持全文搜索、类型筛选、展开长内容和查看原始事件。
- 一键将全部或单段思考翻译成中文，可切回原文，译文自动缓存。
- 顶部下拉列表可切换 JSONL 文件，支持多选导入或一次拖入多个文件；原始日志保持不变。

## 使用

只需 Python 3 和现代浏览器，无需安装第三方依赖。在仓库根目录执行，将示例路径换成自己的事件文件：

```bash
python3 viewer/events.py path/to/events.jsonl --serve
```

打开 [本机阅读器](http://127.0.0.1:8765/events.html)，点击「翻译全部思考」或每段的「翻译为中文」。可用 `--port 8766` 更换端口，按 `Ctrl+C` 停止服务。

文件列表默认查找输入文件所在目录及子目录的事件 JSONL。需要跨运行目录切换时，加 `--files-dir work` 指定查找目录；点击「刷新列表」可发现新导出的日志。选中的本机文件会保留在页面链接中，刷新页面仍可继续查看。也可通过「导入 JSONL 文件」多选文件，在本次页面会话内来回切换。

只需离线阅读时，省略 `--serve`，再用浏览器打开输入文件旁生成的 `events.html`：

```bash
python3 viewer/events.py path/to/events.jsonl
```

## 翻译与文件

默认使用 Google 网页翻译接口，无需模型密钥。新增翻译需要联网，会将对应思考文本发送给 Google；接口可能限流，失败后可重试。若连接需要代理，在启动命令前添加 `TRANSLATION_PROXY=http://127.0.0.1:7890`，端口按本机配置调整。

列表中本机文件的译文分别保存在各自旁的 `events.translations.json`，手动导入的文件也会在浏览器中缓存译文。生成的 HTML 包含已有译文，可离线查看。HTML 包含完整日志，分享时请按原始日志处理。

本目录的 `build.py` 是另一个运行评分看板入口，不属于调用链阅读器。
