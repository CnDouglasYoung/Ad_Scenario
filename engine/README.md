# 回放引擎

按《场景规格 v3》实现。整数记账（1 元 = 100,000 单位），无第三方依赖。

## 跑

```bash
python3 run.py --script 0     # 剧本 0，规则基线，自带对账
python3 run.py --script A
python3 run.py --script B
python3 run.py --script 0 --plans my_plans.json   # 自定义动作
```

`my_plans.json` 格式：

```json
{"1": {"ex1_336x280": {"bid": 90, "budget": 3214286}, "...": {}},
 "2": {...}}
```

## 口径备忘

- **组预算按报价预留**：`max_wins = 预算 // 报价`，达到即该组当日不再赢标
- 赢标：报价 **严格大于** 成交价
- 扣费：一价 = 报价；二价 = 成交价；**Day 3/6** = `max(成交价, ceil(0.8×报价))`
- 日上限软（只记账扣分）；总预算硬（逐笔检查，超额不入账并判负）

## 已知现象（复算得出，非 bug）

出价与点击是**倒 U 型**：出价太低赢不到量，太高则「预算 ÷ 报价」的名额变少。

| 出价 | 点击 | D4-7 曝光 | ROI |
|---:|---:|---:|---:|
| 55 | 330 | 466,689 | 0.91 |
| 70 | 432 | 562,379 | 0.60 |
| **80** | **683** | **619,421** | 0.90 |
| 90（基线） | 645 | 589,383 | 0.79 |
| 150 | 495 | 398,496 | 0.16 |

基线（90/90/100/100）落在峰值的右侧，**峰值约在 80，比基线多 11% 点击**。
